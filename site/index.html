Questions

What is System Data on a Mac, and can Gigapolis clear it?

System Data is the catch-all macOS uses for caches, logs, local Time Machine snapshots and other files it doesn't sort into a category. Gigapolis shows it as its own building so you can see how big it is. Street Sweep clears caches and logs, and Maintenance can remove local Time Machine snapshots, which are often the biggest part. Core macOS files are always left alone.

How is it different from DaisyDisk or WinDirStat?

Those apps map your disk as rings or blocks. Gigapolis maps it as a 3D city, and puts cleaning tools in the same app: Street Sweep, an app uninstaller, duplicate photo finder and Maintenance. It runs on both Mac and Windows, and it's free to start.

Is it safe?

Yes. Gigapolis moves files to the Trash rather than deleting them, and it refuses to touch system folders or your top-level user folders.

Which computers does it run on?

Any Mac on a recent version of macOS (separate downloads for Apple Silicon and Intel), and Windows 10 or 11.

Windows says it "protected your PC". Is that OK?

The Windows version isn't code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway.

Why does it ask for Full Disk Access?

So it can measure everything on your disk, including Mail and Photos. Your files never leave your computer. See our privacy policy.

Is Pro a subscription?

No. $19.99 for a lifetime licence, and you keep Pro including future updates.
